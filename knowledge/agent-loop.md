# 에이전트 루프

에이전트 루프는 모델을 호출하고, 모델이 요청한 Tool을 실행하고, 그 결과를 다시 모델에 넘기는 과정을 반복하는 구조다.
모델이 Tool 요청 없이 텍스트만 답하면 루프가 끝난다.

## 턴과 스텝

사용자 질문 하나와 최종 답변 하나를 턴이라고 한다. 한 턴 안에서 모델을 한 번 호출하는 것을 스텝이라고 한다.
Tool을 쓰는 턴은 스텝이 여러 개가 된다.

## 최대 스텝

모델이 끝까지 Tool만 요청하면 무한히 돌지 않도록 최대 스텝 수에서 멈춘다. 기본값은 10이고, 환경 변수 AGENT_MAX_STEPS로 바꿀 수 있다.
