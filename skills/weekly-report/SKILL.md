# 주간 보고

보고는 이 순서로 쓴다.

1. 한 줄 요약: 이번 주 상태(진행 중, 완료, 위험 중 하나)를 한 문장으로 쓴다.
2. 완료한 일: 끝난 항목만 적는다. 항목마다 결과를 한 줄로 쓴다.
3. 진행 중: 항목, 대략적인 진행률, 다음 확인 시점.
4. 위험과 막힌 일: 무엇이 막혔는지, 누구의 결정이 필요한지.
5. 다음 주 계획: 3개 이하.

작성 규칙:
- 추측은 "추정"이라고 표시한다.
- 숫자(테스트 수, 기간)는 실제로 확인한 값만 쓴다.
- 한 문단은 세 문장을 넘기지 않는다.
- 전체 분량은 A4 한 장을 넘기지 않는다.
